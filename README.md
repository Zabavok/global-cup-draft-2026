# Global Cup Draft 2026

Игровой фэнтези-драфт по составам чемпионата мира 2026.

## Что умеет

- 1 248 игроков из 48 сборных;
- 48 главных тренеров;
- четыре тактические схемы;
- игровой бюджет 120 млн;
- ограничение: не больше трёх игроков одной сборной;
- поиск и фильтры по позиции, сборной и цене;
- автоматическая сборка команды;
- итоговый рейтинг с объяснением;
- автосохранение состава в браузере;
- адаптивный интерфейс для компьютера и телефона.

## Запуск

```bash
pnpm install
pnpm dev
```

Затем открыть адрес, показанный в терминале.

## Данные и оценки

Составы, тренеры и турнирная статистика взяты из открытого набора
[Mominullptr/fifa-world-cup-2026-dataset](https://huggingface.co/datasets/Mominullptr/fifa-world-cup-2026-dataset)
под лицензией CC0-1.0.

Игровые цены и рейтинги рассчитываются внутри проекта. Они нужны для баланса
драфта и не являются официальными трансферными оценками.

Проект не связан с FIFA и не использует официальную символику турнира.
